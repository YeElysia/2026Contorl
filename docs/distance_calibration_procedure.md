# 底盘距离标定流程

## 准备工作

### 硬件准备
1. 确保底盘四个麦轮接触良好，无明显磨损
2. 在平整地面（水泥地或瓷砖）进行测试
3. 准备卷尺（至少 2 米）和胶带
4. 确保电池电量充足（建议 > 80%）

### 标记起点
1. 在地面用胶带标出十字线，作为底盘中心起点
2. 用胶带标出车头方向（Y 轴正方向）
3. 预留至少 1.5 米的测试空间（四个方向）

## 测试步骤

### 1. 编译并烧录测试程序
```bash
pio run -e distance_calibration_test -t upload
```

### 2. 启动测试
1. 将底盘放置在起点标记处，车头对准 Y 轴
2. 上电，等待状态灯熄灭（IMU 就绪）
3. 串口输出显示当前标定系数和操作说明

### 3. 测试每个方向

#### 选择方向
- **短按按键**：循环选择方向（前 → 后 → 左 → 右）
- 状态灯闪烁次数表示当前方向：
  - 1 次：前进（Forward）
  - 2 次：后退（Backward）
  - 3 次：左移（Left）
  - 4 次：右移（Right）

#### 执行测试
1. **长按按键 1 秒**启动测试
2. 状态灯常亮，底盘开始移动
3. 底盘移动 1000mm 后自动停止
4. 状态灯闪烁 2 次表示完成

#### 测量实际距离
1. 用卷尺测量底盘中心到起点标记的**实际距离**
2. 记录测量值（精确到 1mm）

### 4. 读取串口输出

测试完成后，串口输出示例：
```
========================================
CALIB_DONE direction=FORWARD
  Elapsed: 3250 ms
  Target distance: 1000 mm
  Odometry distance: 1023.4 mm
  Delta X: -2.1 mm, Delta Y: 1023.2 mm
  ---
  Current FORWARD_DISTANCE_SCALE: 1.0000
  ---
  [ACTION REQUIRED]
  1. Measure ACTUAL distance traveled from start mark
  2. Calculate new scale = 1000.0 / measured_distance
     If odometry (1023.4 mm) is accurate:
     Suggested FORWARD_DISTANCE_SCALE = 0.9771
  ---
  Heading drift: 0.8 degrees
  Heading drift within acceptable range
========================================
```

### 5. 计算标定系数

**假设实际测量距离为 980mm：**

```
新标定系数 = 1000.0 / 980.0 = 1.0204
```

**更新 `include/chassis_config.h`：**
```cpp
constexpr float FORWARD_DISTANCE_SCALE = 1.0204f;
```

### 6. 重复测试其他方向

完成一个方向后：
1. 将底盘放回起点标记
2. 短按按键选择下一个方向
3. 重复步骤 3-5

**建议测试顺序**：前 → 后 → 左 → 右

## 标定系数更新

编辑 `include/chassis_config.h`，更新四个方向的系数：

```cpp
// 示例：根据实际测量调整
constexpr float FORWARD_DISTANCE_SCALE = 1.0204f;   // 实测 980mm
constexpr float BACKWARD_DISTANCE_SCALE = 0.9852f;  // 实测 1015mm
constexpr float RIGHT_DISTANCE_SCALE = 1.0526f;     // 实测 950mm
constexpr float LEFT_DISTANCE_SCALE = 1.0101f;      // 实测 990mm
```

## 航向偏移诊断

### 正常范围
- **可接受**: ±2° 以内
- **需要调查**: ±2° ~ ±5°
- **必须修正**: > ±5°

### 偏移原因和解决方案

#### 1. 左右轮直径不一致
**现象**: 前进/后退时持续向一侧偏移

**解决方案**:
- 检查左右轮磨损程度
- 更换磨损严重的轮子
- 微调 `MOTOR_SIGN` 或单侧速度补偿

#### 2. 电机方向配置错误
**现象**: 移动轨迹呈弧线

**解决方案**:
检查 `chassis_config.h` 中的：
```cpp
constexpr int8_t MOTOR_SIGN[4] = {-1, 1, -1, 1};
//                                 LF  RF  LR  RR
```

#### 3. 麦轮安装角度偏差
**现象**: 横移时也产生航向偏移

**解决方案**:
- 检查四个麦轮的安装方向
- 确保小滚子与车体成 45° 角

#### 4. IMU 安装不水平
**现象**: 所有方向的偏移都不稳定

**解决方案**:
- 检查 IMU 安装是否水平
- 重新校准 IMU（如果支持）

#### 5. 地面不平整
**现象**: 重复测试结果不一致

**解决方案**:
- 更换测试场地
- 在多个位置重复测试取平均值

## 航向保持增强

如果航向偏移持续存在，可以调整航向控制参数：

### 1. 提高修正增益
编辑 `include/chassis_config.h`：
```cpp
// 原值
constexpr float HEADING_KP_STEPS_PER_S_PER_DEG = 35.0f;
constexpr float HEADING_MAX_CORRECTION_RATIO = 0.30f;

// 增强版（更激进的修正）
constexpr float HEADING_KP_STEPS_PER_S_PER_DEG = 50.0f;
constexpr float HEADING_MAX_CORRECTION_RATIO = 0.45f;
```

### 2. 针对斜移优化
如果斜移时偏航严重，考虑分离控制策略（需要修改代码）

## 验证标定结果

### 完整路线测试
标定完成后，运行一个综合测试：
```
前进 1000mm → 右移 500mm → 后退 1000mm → 左移 500mm
```

**期望结果**: 回到起点 ±20mm 以内

### 长距离测试
测试 2000mm 距离，验证标定系数的线性度

## 故障排查

### 问题：里程计距离与实际差距超过 10%
**可能原因**:
- 轮径配置错误（检查 `WHEEL_DIAMETER_MM`）
- 细分数配置错误（检查 `MICROSTEPS`）
- 轮子严重打滑

### 问题：每次测试结果差异超过 30mm
**可能原因**:
- 地面摩擦力不均匀
- 电池电压不稳定
- 轮子与地面接触不良

### 问题：启动时报错 "IMU not ready"
**解决方案**:
- 检查 JY901 接线（RX/TX 是否正确）
- 检查波特率是否为 115200
- 重新上电

## 高级标定

### 速度相关的标定
如果发现高速和低速的距离系数不同，可以：
1. 分别用快速档和精确档测试
2. 记录两组标定系数
3. 在代码中实现速度补偿

### 负载相关的标定
如果机械臂负载影响底盘精度：
1. 在机械臂不同姿态下重复标定
2. 使用加权平均值

## 注意事项

1. **每次修改标定系数后都要重新编译并烧录**
2. **标定时底盘上不要放置额外物品**
3. **确保测试环境光线充足，便于测量**
4. **建议每个方向测试 3 次取平均值**
5. **标定数据记录在笔记本上，便于回溯**
